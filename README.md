# Vericred Voidx

Role & Constraint: You are a senior product designer. Build a website that looks hand-crafted, editorial, and high-craft—completely avoiding generic "AI template" aesthetics.

Strict Prohibitions (Zero-Tolerance):

Do not use purple or violet gradients, neon glowing blurs, or generic dark-mode cyberpunk tropes.

Do not use Inter, Roboto, or system-default sans-serif fonts. Pick a distinct, characterful typography pairing (e.g., a crisp editorial serif for headings + a clean humanist sans for body).

Do not use emojis as UI icons or decorative badges.

Do not put heavy drop-shadows or 1px colored/gradient borders around every card or button.

Do not use symmetrical, centered "hero banner + 3 equal feature cards" default layouts. Use an asymmetric, editorial, or split-screen grid.

Design Direction:

Color Palette: Choose a restrained, earthy, or high-contrast monochromatic palette with a single intentional accent color (max 1–2 colors total).

Spacing & Hierarchy: Use generous, intentional whitespace, strict 8px grid alignment, and tight, punchy, human-sounding copy (no buzzword-heavy AI fluff like "In today's fast-paced digital world...").

Visual Assets: Use real-world layout composition, staggered blocks, or masonry styles instead of generic centered stock photography blocks. improve the website and don't let the text in design overlap
